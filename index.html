2. Testing Instructions

Invalid Email Test

On the login or registration page, enter an email without the @ symbol (e.g., rajeshgmail.com). The form will trigger built-in HTML5 and JavaScript email syntax validation displaying: "Please enter a valid email address."

Duplicate Email Test

Attempt to register with an existing email such as admin@agentpro.com. The system detects uniqueness and displays: "This email is already registered. Please log in."

Wrong Password & Rate Limiting

Enter an incorrect password. A secure generic error "Invalid email or password." is shown without revealing account existence. After 3 failed attempts, temporary rate limiting blocks login for 30 seconds.

Role-Based Access Control

Switch roles using the top-right role switcher or Admin tab to test Agent, Manager, and Admin permissions across modules.
